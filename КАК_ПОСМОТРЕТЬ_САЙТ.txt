ДЛЯ ПОЛНОЙ ВЕРСИИ (С КОРЗИНОЙ, ФИЛЬТРАМИ И Т.Д.):
═══════════════════════════════════════════════════════════════

Нужно установить Node.js:

1. Скачайте: https://nodejs.org/ (LTS версия)

2. Установите (просто "Далее-Далее-Готово")

3. Перезапустите командную строку

4. Откройте PowerShell в папке C:\Users\ART\furniture-store

5. Выполните:
   npm install
   npm run dev

6. Откройте браузер по адресу из консоли (обычно http://localhost:5173)
