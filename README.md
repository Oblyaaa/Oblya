## Искусственное «состаривание» почерка по изображению (Python)

Этот проект принимает изображение с рукописным текстом и генерирует «состаренную» версию, имитируя ряд признаков, которые описаны в судебно‑почерковедческой и графологической литературе для почерка пожилых авторов: замедление темпа и дрожание, недописанные конечные элементы, нарушение базовой строки, вариативность нажима, упрощение элементов, исправления/зачёркивания, а также визуальное «старение» бумаги (пожелтение, пятна, лёгкая зернистость).

### Быстрый старт

1) Установка зависимостей:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

2) Запуск на вашей картинке:

```bash
python handwriting_aging.py input.jpg output.jpg --severity 0.6 --seed 42 --smudges --strikethroughs
```

- `--severity` в диапазоне [0..1] задаёт общую «силу» эффектов.
- Дополнительные флаги: `--smudges` (смазы), `--strikethroughs` (зачёркивания).
- Можно отключать отдельные блоки: `--no-warp`, `--no-pressure`, `--no-incomplete`, `--no-paper`.

### Что реализовано (соответствие признаков — методам)

- Замедление темпа, дрожание, базовая строка «гуляет»:
  - Низкочастотная эластическая деформация изображения и маски штрихов (coherent noise + remap), локальные микродеформации имитируют дрожь и непопадание в линейку.
- Вариативность нажима (неравномерная толщина/насыщенность штрихов):
  - Морфологическое утолщение/истончение штрихов с управлением плавным шумом (noise‑guided blending), затем лёгкое «растекание» (bleed).
- Недописанные конечные буквы/штрихи:
  - Поко-мпонентное ослабление правых участков связных компонентов (alpha‑fade по bbox, вероятностно).
- Упрощение строения знаков, мелкие «огрехи» формы:
  - Совмещённый эффект эластической деформации, bleed и вариативности нажима.
- Исправления/зачёркивания, смазы:
  - Опционально добавляются случайные тонкие линии‑зачёркивания и полупрозрачные смазы вокруг штрихов.
- Старение бумаги:
  - Тёплый тон (слегка сепийный), виньетирование, мягкие пятна/«foxing», лёгкая зернистость.

### Ограничения и замечания

- Скрипт работает в полностью «оффлайн» режиме (без нейросетей) и не меняет содержание текста, а лишь пластически и визуально модифицирует уже имеющиеся штрихи.
- В реалистичных настройках держите `--severity` в пределах 0.3–0.7.
- Результат — это художественная имитация, не предназначенная для обмана экспертов. Для учебных/научных демонстраций.

### Параметры CLI

```text
usage: handwriting_aging.py input output [--severity FLOAT] [--seed INT]
                                   [--no-warp] [--no-pressure]
                                   [--no-incomplete] [--no-paper]
                                   [--strikethroughs] [--smudges]
```

- `--severity`: общая интенсивность эффектов [0..1].
- `--seed`: фиксирует генератор случайностей для воспроизводимости.
- `--no-warp`: отключить геометрические деформации.
- `--no-pressure`: отключить вариативность нажима.
- `--no-incomplete`: отключить недописанные окончания.
- `--no-paper`: отключить «старение» бумаги.
- `--strikethroughs`: добавить редкие зачёркивания.
- `--smudges`: добавить лёгкие смазы вокруг штрихов.

### Обзор литературы (кратко)

Ниже собраны базовые источники, где описаны наблюдаемые у пожилых авторов особенности почерка, а также работы по редактированию текста на изображениях и по используемым приёмам искажения:

- Судебно‑почерковедческие источники (об общих закономерностях, естественной вариативности и возрастных изменениях):
  - Huber, R. A., Headrick, A. M. Handwriting Identification: Facts and Fundamentals. CRC Press, 1999. — Классический справочник по идентификации почерка; обсуждает естественную вариативность, признаки замедления, дрожания, неритмичности.
  - Koppenhaver, K. M. Forensic Document Examination: Principles and Practice. Humana Press, 2007. — Практическое руководство по судебной экспертизе документов, включая особенности штрихов при треморе и слабом моторном контроле.
  - Osborn, A. S. Questioned Documents. 2nd ed., 1929. — Исторический фундамент дисциплины; обсуждаются признаки, возникающие при затруднённом письме, медленном темпе, дрожи.
  - «Возрастные изменения и естественная вариационность почерка». — Обзорная статья на русскоязычном экспертном ресурсе, где перечислены типичные признаки: замедление, недописанные элементы, нарушение строк/полей, изменения наклона и интервалов, упрощение конструкций, исправления и др. [ekspertiza‑reshenie.ru](https://ekspertiza-reshenie.ru/articles/vozrastnye-izmeneniya-i-estestvennaya-variatsionnost-pocherka/)

- Клинические и моторные аспекты (для обоснования «дрожи», микродеформаций и микроигры толщины):
  - Teulings, H.-L., Stelmach, G. E. Control of stroke size, peak acceleration, and duration in Parkinsonian handwriting. Human Movement Science, 1991. — Исследования моторного контроля и микрографии при болезни Паркинсона (уменьшение размера, дрожание, неритмичность).
  - Van Gemmert, A. W. A., Teulings, H.-L., Stelmach, G. E. Parkinsonian handwriting: character size and writing speed. Acta Psychologica, 2001. — Связь скорости, размера и вариативности штриха.

- Изменение/редактирование текста на изображениях (альтернативные подходы):
  - Roy et al. STEFANN: Scene Text Editor using Font Adaptive Neural Network. arXiv:1903.01192. — Нейросетевое редактирование текста на изображениях с сохранением стиля.
  - Brooks et al. InstructPix2Pix: Learning to Follow Image Editing Instructions. arXiv:2211.09800. — Обучение редактированию изображений по текстовым инструкциям.
  - Simard, Steinkraus, Platt. Best Practices for Convolutional Neural Networks applied to Visual Document Analysis, 2003. — Классические «эластические искажения» для рукописного текста (идея, близкая к применённому в скрипте warping).

Приведённый здесь код воспроизводит часть описанных феноменов средствами классической обработки изображений (OpenCV/NumPy), без обучения моделей. Это даёт управляемость и воспроизводимость для учебной демонстрации признаков.

### Структура проекта

- `handwriting_aging.py` — основной скрипт с конвейером: сегментация штрихов → геометрические и морфологические трансформации → рендеринг → «старение» бумаги → опциональные артефакты.
- `requirements.txt` — зависимости (OpenCV, NumPy, Pillow, SciPy).

### Юридические и этические оговорки

Инструмент предназначен для обучения/научных демонстраций. Не используйте для подделки документов или введения в заблуждение экспертов. Реальные судебные признаки оцениваются комплексно; имитация не заменяет экспертный анализ.
