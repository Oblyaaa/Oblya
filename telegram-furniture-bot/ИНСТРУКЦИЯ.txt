🔗 ССЫЛКА НА САЙТ
───────────────────────────────────────────────────────────────
• В боте есть ссылка на сайт магазина
• Кнопка "Открыть сайт" в главном меню и разделе "О магазине"
• Бот работает независимо от сайта

ШАГ 1: УСТАНОВИТЕ PYTHON
───────────────────────────────────────────────────────────────
1. Скачайте Python с официального сайта: https://www.python.org/
2. При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH"
3. Установите Python

ШАГ 2: УСТАНОВИТЕ ЗАВИСИМОСТИ
───────────────────────────────────────────────────────────────
Откройте командную строку (cmd) или PowerShell в папке проекта и выполните:

    pip install -r requirements.txt

ШАГ 3: СОЗДАЙТЕ БОТА В TELEGRAM
───────────────────────────────────────────────────────────────
1. Откройте Telegram
2. Найдите бота @BotFather
3. Отправьте команду: /newbot
4. Введите имя вашего бота (например: МебельПремиум Бот)
5. Введите username бота (должен заканчиваться на "bot", например: mebelpremium_bot)
6. BotFather отправит вам ТОКЕН - скопируйте его

ШАГ 4: НАСТРОЙТЕ ТОКЕН И URL САЙТА
───────────────────────────────────────────────────────────────
Создайте файл .env в папке проекта со следующим содержимым:

    BOT_TOKEN=ваш_токен_здесь
    SITE_URL=https://your-site.com

Или для локальной разработки (когда сайт запущен на localhost:5173):

    BOT_TOKEN=ваш_токен_здесь
    SITE_URL=http://localhost:5173

ВАРИАНТ 2:
Откройте файл config.py и замените:
    BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE'
    SITE_URL = 'https://your-site.com'
на ваши значения.

ШАГ 5: ЗАПУСТИТЕ БОТА
───────────────────────────────────────────────────────────────
В командной строке в папке проекта выполните:

    python bot.py

Если все правильно, вы увидите:
    🤖 Бот запущен!
    Для остановки нажмите Ctrl+C

ШАГ 6: ПРОТЕСТИРУЙТЕ БОТА
───────────────────────────────────────────────────────────────
1. Откройте Telegram
2. Найдите вашего бота по username
3. Отправьте команду /start
4. Протестируйте все функции
5. Проверьте ссылку на сайт в разделе "О магазине"

ВАЖНЫЕ ЗАМЕЧАНИЯ:
═══════════════════════════════════════════════════════════════

• Токен бота - это секретная информация! Не публикуйте его!
• Файл .env не должен попадать в git (он уже в .gitignore)
• Для остановки бота нажмите Ctrl+C в терминале
• Данные корзины сохраняются в файл user_carts.json
• SITE_URL опционален - используется только для отображения ссылки на сайт

═══════════════════════════════════════════════════════════════
ПРОБЛЕМЫ И РЕШЕНИЯ:
═══════════════════════════════════════════════════════════════

❌ "pip не является внутренней командой"
   → Python не установлен или не добавлен в PATH
   → Переустановите Python с отметкой "Add to PATH"

❌ "No module named 'telegram'"
   → Зависимости не установлены
   → Выполните: pip install -r requirements.txt

❌ "Invalid token"
   → Неправильный токен
   → Проверьте токен в .env или config.py

❌ Ссылка на сайт не отображается
   → Проверьте SITE_URL в .env или config.py (опционально)
   → Бот работает даже без SITE_URL, просто ссылка не будет отображаться
