# 🤖 Telegram Бот для Мебельного Магазина

Полнофункциональный Telegram бот для интернет-магазина мебели.

## 🔗 Информация о сайте

В боте есть ссылка на сайт магазина:
- ✅ Кнопка "Открыть сайт" в главном меню
- ✅ Информация о сайте в разделе "О магазине"

## 🚀 Возможности

- ✅ Каталог товаров по категориям
- ✅ Просмотр детальной информации о товарах
- ✅ Корзина покупок
- ✅ Управление количеством товаров
- ✅ Оформление заказов
- ✅ Информация о магазине и контактах
- ✅ Ссылка на сайт магазина
- ✅ Красивый интерфейс с inline-кнопками

## 📋 Установка

### 1. Установите Python 3.8+

### 2. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 3. Создайте бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и создайте бота
4. Сохраните полученный токен

### 4. Настройте бота

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
SITE_URL=https://your-site.com
```

**Для локальной разработки:**
```env
SITE_URL=http://localhost:5173
```

**Примечание:** `SITE_URL` используется только для отображения ссылки на сайт в информации о магазине. Бот не связан с сайтом через товары.

## 🎮 Запуск

```bash
python bot.py
```

## 📱 Команды бота

- `/start` - Главное меню
- `/catalog` - Каталог товаров
- `/cart` - Корзина
- `/about` - О магазине

## 🔗 Ссылка на сайт

В боте есть ссылка на сайт магазина, которая отображается:
- В приветственном сообщении (`/start`)
- В разделе "О магазине"
- URL сайта настраивается в файле `.env` или `config.py`

Бот работает независимо от сайта - товары и корзина в боте не связаны с сайтом.

## 🛠️ Структура проекта

```
telegram-furniture-bot/
```

## 📦 Функционал

### Каталог
- Просмотр товаров по категориям
- Фильтрация по категориям
- Детальная информация о каждом товаре

## ⚙️ Настройка

### Изменение URL сайта:

1. В файле `.env`:
   ```env
   SITE_URL=https://your-site.com
   ```

2. Или в файле `config.py`:
   ```python
   SITE_URL = 'https://your-site.com'
   ```

### Изменение товаров:

Товары определены в `data/products.py`. Каждый товар имеет:
- `id` - уникальный идентификатор товара
- `category` - категория товара
- `price` - цена
- `description` - описание
- И другие характеристики

## 📝 Примечания

- Данные корзины сохраняются в файл `user_carts.json`
- Каждый пользователь имеет свою корзину
- После оформления заказа корзина очищается
- Бот работает независимо от сайта
